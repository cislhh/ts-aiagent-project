# 微信公众号从零到变现：事实基线

- 研究工单：cislhh/ts-aiagent-project issue #8
- 调研日期 / 全部来源访问日期：**2026-11-11**
- 面向场景：前端工程师，个人主体，macOS + DSH 本地环境，不部署服务器，最终由本人手动发布「前端 × AI」内容
- 标注约定：**[官方]** = 微信/腾讯官方文档或客服中心、国家网信办原文；**[媒体]** = 主流媒体转述官方口径；**[社区]** = 运营者社区经验，官方未背书；**[推断]** = 由官方文档字面推出的结论，需实测；**❓** = 本次未查到可核验来源

## 0. 五条结论先行

1. **个人主体今天只能注册订阅号，且不能微信认证**：微信公众平台注册页把「服务号」定位为「适合企业及组织注册」，客服明确「个人主体类型公众号暂不支持申请微信认证」[25][3]。实名 ≠ 认证。
2. **个人主体 2025 年 7 月起被回收「发布」接口权限**，官方文档原话：个人主体账号、企业主体未认证账号将被回收发布能力（freepublish/*）的调用权限[15]。注意：**企业主体不认证一样没有发布接口**，所以「企业 + API」的真实门槛是「营业执照 + 300 元/年认证」，不是「营业执照」。
3. **流量主门槛是 100 关注用户，不是 500**（官方客服页 2026-11-11 仍写 100）[8]；赞赏只需「发表过原创文章」即可邀请开通，最多 3 个赞赏账户[9]；付费阅读需「注册 > 3 个月 + 近 3 个月无严重违规 + ≥ 3 篇原创」[11]。
4. **2026-03-27 起，《微信公众平台运营规范》新增 3.27「非真人自动化创作行为」**：不得利用 AI、脚本、接口或其他自动化方式替代真人完成内容创作、发布等流程；处罚含流量限制、删文、能力限制、封禁[30][31]。这条与「用 API 自动发布」直接冲突——**个人主体 + 手动发布反而是当前最安全的形态**。
5. **新注册账号没有留言功能**（官方客服："后续新注册账号无留言功能"）[12]，这意味着新号拿不到「留言区广告」这个广告位，也让「留言互动涨粉」这条路从一开始就不成立。

## 1. 账号类型对比：个人订阅号 / 企业（个体户）订阅号 / 服务号

### 1.1 注册门槛与材料

官方注册说明给出的材料清单（原表按主体类型列）[1]：

| 项目 | 个人类型 | 个体工商户 | 企业类型 |
| --- | --- | --- | --- |
| 主体名称 | — | 个体户名称 | 企业名称 |
| 主体证照 | — | 营业执照注册号/统一信用代码 | 营业执照注册号/统一信用代码 |
| 运营者 | 身份证姓名 + 号码 | 身份证姓名 + 号码 | 身份证姓名 + 号码 |
| 手机 | 运营者手机号 | 运营者手机号 | 运营者手机号 |
| 微信 | 已绑定运营者银行卡的微信号 | 已绑定运营者银行卡的微信号 | 已绑定运营者银行卡的微信号 |
| 对公账户 | — | —（可用法定代表人验证或微信认证替代） | 企业对公账户 |

- 注册入口的第一步就要选账号类型：**公众号（订阅号）「适合个人及媒体注册」，服务号「适合企业及组织注册」**；主体类型选项为 政府 / 媒体 / 企业 / 其他组织 / 个人[25]。因此个人主体实际上只有订阅号可选。
- **同一个身份证注册个人类型公众号数量上限为 1 个**；同一手机号最多绑定 5 个账号；扫码验证的微信号最多绑定 5 个公众号[5]。选错类型 / 用掉唯一名额的代价很高（见 1.4）。
- 三种主体验证方式及审核时长（企业/个体户）[1]：
  - **支付验证（小额打款）**：10 天内向指定账户打款，收到后 1 个工作日验证；金额 10 个工作日内原路退回。
  - **法定代表人验证**：1–5 个工作日工商数据校验；**仅支持企业和个体工商户**。
  - **微信认证验证**：30 个自然日内完成认证，审核费 300 元/年，支付后 1–5 个工作日审核。
- 个人主体没有「主体验证」环节（身份证实名），官方客服页也**没有给出个人注册的审核时长**，只说「以页面/通知中心为准」→ ❓ 个人注册审核时长未查到官方数字。

### 1.2 费用与认证

| 项目 | 事实 | 来源 |
| --- | --- | --- |
| 注册费 | 官方只列了认证费，注册本身未见收费项 | [1][2] |
| 微信认证费 | **300 元/次，一年一审**；只支持微信支付，任意个人微信可扫码；**认证失败也收费、不退还** | [2] |
| 个人主体能否认证 | **不能**。「个人主体类型公众号暂不支持申请微信认证」 | [3] |
| 非个人主体认证前置 | 若注册时走小额打款/法人验证，需完成验证后才能申请认证；若注册时直接选微信认证，注册后即可申请 | [3] |
| 免费认证的例外 | 政府类型中的「机关单位」；其他组织中的「基金会、国外政府机构驻华代表处」 | [2] |

**认证后多什么能力**（官方口径比较概括：「更丰富的高级接口」+ 认证标识）[13][4]：

- 微信客户端展示认证标识、可点开看主体资料[13]；
- 自定义菜单完整能力：未认证订阅号的菜单「跳转网页」**只能跳图文素材**，不能跳其他网址；「发送信息」不支持纯文字[4]；
- 微信支付：**服务号可申请；订阅号只有政府、媒体类型可申请**——即企业/个体户的订阅号也**不能**接微信支付[4]；
- 2025-07 之后，「发布接口」实际上也变成认证专属（未认证企业同样被回收）[15]；
- 一次性订阅消息模板 ID 等能力仅认证账号可见[23]。

### 1.3 群发频次与基础能力

- 订阅号：**每天群发 1 次**；服务号：**每月群发 4 次**（认证与否都一样）[4]。
- 新注册账号**没有留言功能**[12]。
- 公众号（原订阅号）**不能迁移成服务号**；主体也不能直接变更，只能走「账号迁移」[14]。

### 1.4 类型/主体选错的补救成本

- 账号迁移可把原创保护、留言管理、违规记录、关注用户（可选）、文章素材（可选）、微信号（可选）迁到另一个号；**不支持公众号（订阅号）迁移至服务号**；目标主体**不能是个人类型**（唯一例外：个体工商户可迁到法人个人）[14]。
- 异主体迁移：**300 元审核费 + 申请公函公证**（1–2 个工作日出公证），审核 1–3 个工作日，迁移执行 1–3 天；审核失败不退费[14]。
- 也就是说：先用个人号起步，之后想升级成企业服务号，**不能迁移，只能注销重注册**，个人号的粉丝/原创标识/违规记录都带不过去（订阅号→服务号被明确排除）[14]。

## 2. 流量主：开通条件、广告形式、分成与收益

### 2.1 开通条件（官方）

- **公众号/服务号关注用户达到 100 以上**即可开通；**同一主体开通流量主上限 20 个**；**存在刷粉行为不支持开通**[8]。
- 申请路径：微信公众平台 → 流量主 → 申请开通 → 同意协议 → 选择广告位并提交；开通后需补结算信息[8]。
- 官方条件里**没有**「必须原创」「必须认证」「注册满 N 个月」的要求[8]。原创只影响分成（见 2.3，社区口径）与「原创标识」。
- 个人订阅号**可以**开通流量主：开通条件只与关注用户数、刷粉、同主体数量上限有关，与主体类型/认证无关[8]。

### 2.2 广告形式（官方接口枚举，等于官方承认的广告位清单）

微信官方「广告数据分析接口」把公众号广告位枚举为 5 类[22]：

| 广告位枚举 | 含义 |
| --- | --- |
| `SLOT_ID_BIZ_BOTTOM` | 公众号底部广告 |
| `SLOT_ID_BIZ_MID_CONTEXT` | 公众号文中广告 |
| `SLOT_ID_BIZ_VIDEO_END` | 公众号视频后贴 |
| `SLOT_ID_BIZ_SPONSOR` | 公众号互选广告 |
| `SLOT_ID_BIZ_CPS` | 公众号返佣商品 |

- 注意官方枚举里**没有「留言区广告」**；且新号无留言[12]，所以实际可用的只有底部/文中/视频后贴/互选/返佣。
- 数据接口按广告位返回 `exposure_count`、`click_count`、`income`（单位：分）、`ecpm`（千次曝光收益，分），说明计费同时存在曝光与点击两种口径[22]。
- 结算按**半月**区间（接口字段：`order` 1 = 上半月，2 = 下半月；状态 1 结算中 / 2、3 已结算 / 4 付款中 / 5 已付款）[22]。

### 2.3 分成机制

- **官方公开文档里没有统一分成比例**（流量主服务协议在广告平台后台，需登录，本次未取得原文）→ ❓ 官方比例未核实。
- 社区/第三方普遍口径：**原创文章 70%、非原创/转载 50%**；并称 2026-03-31 起文中/文末广告改为**纯 CPC 计费（取消曝光收益）**，留言区广告暂留 CPM[32][33]。
  - 这两条**只有社区来源、无官方文档佐证**，且直接影响收入模型，务必以后台《流量主服务协议》与结算单为准。

### 2.4 真实收益区间

- **没有可核验的官方区间**，本次也未找到可交叉验证的一手数据 → 不给「区间」数字，避免误导。
- 可确认的结构性事实：收益 = 各广告位 `income` 累加，按半月结算，平台代扣税费；`ecpm` 与 `click_rate` 因广告位/内容品类差异极大[22]。
- 社区样本差异大到没有参考价值（同一「万次阅读」有人报个位数元、有人报数十元），因此**任何「万阅读 = X 元」的说法都不应写进决策依据**（❓ 记为不确定项）。

## 3. 其他变现方式与门槛

| 变现方式 | 门槛（官方） | 关键细节 | 来源 |
| --- | --- | --- | --- |
| **赞赏（喜欢作者）** | **发表过原创文章后即可邀请创建赞赏账户** | 一个公众号最多邀请 3 个赞赏账户；赞赏账户需实名、且需已关注该号；同一身份证只能开 1 个赞赏账户；资金 T+7 结算到作者个人微信；**付费文章不支持赞赏** | [9][11] |
| **付费阅读（付费图文）** | **注册超过 3 个月 + 近 3 个月无严重违规 + 已发表至少 3 篇原创文章** | 定价 1~10000 微信豆；仅支持单篇，无包月/包年；只支持微信豆购买（iOS/安卓均需先充值）；收益 = 原始收入 − 个税 − 委托代征增值税（超起征点且主体为自然人时）− 附加税（增值税 × 10%）；政府/媒体/企业账号同样全量开放 | [11] |
| **互选广告（官方撮合接单）** | ❓ 官方页面为登录态 SPA，未取得原文；社区口径为**粉丝 ≥ 500 且已开通流量主** | 广告主在互选平台选号、号主报价成交；单价通常远高于底部广告 | [22][34]（门槛为社区口径） |
| **返佣商品 / 带货（CPS）** | ❓ 官方门槛未见公开页；社区口径为**开通流量主后可开带货能力，约 100 粉起** | 官方草稿接口错误码含 `53406 请先开通带货能力`、`53404 账号已被限制带货能力`，说明带货是独立开关，且可被平台单独限制 | [19][22] |
| **软广/广告主直投（私下接单）** | 平台无粉丝门槛，但内容受《微信公众平台运营规范》与《广告法》约束 | 商业推广需可识别（标注「广告」），医疗/金融/教育等类目另需资质；平台可判定「违规推广」处罚 | [30]（规范层） |
| **「广告主」** | 这是**花钱投放**的一方（开户充值），不是变现方式 | 别把「广告主」当成接单渠道 | [22] |

补充：公众号**没有「付费专栏」这种产品形态**，付费能力只有「单篇付费图文」[11]；想做专栏/社群只能外链（订阅号菜单外链又受未认证限制[4]）。

## 4. API 权限：草稿箱、发布、图片上传、素材

### 4.1 能力与配额（官方文档）

| 能力 | 接口 | 每日限额 | 关键约束 | 来源 |
| --- | --- | --- | --- | --- |
| 新增草稿 | `POST /cgi-bin/draft/add` | **1000** | 标题 ≤ 32 字、作者 ≤ 16 字、摘要 ≤ 120 字、正文 < 2 万字符且 < 1MB；正文图片 URL **必须**来自 `uploadimg`；封面 `thumb_media_id` 必须是永久素材 | [18][19] |
| 获取/删除/改草稿 | `draft/batchget`、`draft/delete`、`draft/update` | 500 / 1000 / 1000 | — | [18] |
| 上传图文内图片 | `POST /cgi-bin/media/uploadimg` | 未单列（素材类上传合计口径见 `media/upload` 100000） | **jpg/png，≤ 1MB**；不占素材库 10 万张限额 | [20][18] |
| 上传永久素材 | `POST /cgi-bin/material/add_material` | 同上传类 | 图文/图片素材上限 100000，其他 1000；图片 ≤ 10M；返回的 URL 只能在腾讯系域名使用 | [21] |
| 上传临时素材 | `POST /cgi-bin/media/upload` | 100000（下载 200000） | 媒体文件只保存 **3 天**，3 天后 media_id 失效 | [26][18] |
| 发布 | `POST /cgi-bin/freepublish/submit` | **100** | — | [15][18] |
| 发布状态/列表/删除/取文章 | `freepublish/get`、`batchget`、`delete`、`getarticle` | 100 / 100 / 10 / 100 | — | [18] |

其他限额（官方）[18]：`access_token` 2000/日、自定义菜单创建 1000/日、客服消息 500000/日、高级群发 100/日、上传图文消息接口 10/日、获取关注者列表 500/日。粉丝数超过 10W/100W/1000W 时部分接口上限会提升，以后台「开发者中心 → 接口权限」页面数字为准[18]。

### 4.2 个人主体到底有没有权限（这是本题最关键的一条）

官方文档在「发布能力」页（订阅号与服务号两版都有）明确加注：

> 注：2025年7月起，个人主体账号、企业主体未认证账号及不支持认证的账号将被回收以上接口的调用权限。[15]

由此可得：

1. **个人主体：没有 `freepublish/*`（发布）权限**——2025-07 起被回收。
2. **企业主体但未认证：同样没有发布权限**。所以「企业主体 + API 发布」= 营业执照 **且** 300 元/年认证，二者缺一不可[15][2]。
3. **草稿箱与素材接口未见同类限制**：`draft/*`、`material/*`、`media/uploadimg` 的文档都**没有**这条 2025-07 注记[16][17][19][20][21]。→ **[推断]** 个人主体仍可调用 `draft/add` + `uploadimg`，把排版好的图文推进草稿箱，再在后台手动点「发表」。**必须在开通后到「接口权限」页实测**（见第 8 节不确定项）。
4. 个人主体能拿到 AppSecret 吗？能：开发者平台说明里，个人主体只需**管理员实名**即可启用 AppSecret（提示语是「该账号尚未完成实名」），非个人主体才需要「主体认证」[23]。
5. **IP 白名单是硬门槛**：调用 `access_token` 的请求 IP 必须在白名单内，否则报 `40164`[23][24]；`access_token` 有效期 7200 秒、需中控刷新[24]。对「本地 macOS、不部署服务器、家庭宽带动态 IP」这是实打实的运维摩擦：要么频繁改白名单，要么用固定出口 IP 的云函数（等于变相部署）。
6. 第三方代调用（服务商）会消耗公众号自身的 quota[18]。

### 4.3 未认证 vs 认证（API 视角小结）

| 能力 | 个人（未认证） | 企业未认证 | 企业已认证 |
| --- | --- | --- | --- |
| draft/add、uploadimg、永久素材 | [推断] 可用 | 可用 | 可用 |
| freepublish/submit 发布 | ❌ 2025-07 回收[15] | ❌ 回收[15] | ✅ |
| 微信支付 | ❌（个人不可认证；订阅号仅政府/媒体可申请）[3][4] | ❌ | 服务号 ✅ / 企业订阅号 ❌[4] |
| 自定义菜单跳外链 | ❌ 仅能跳图文素材[4] | ❌ | ✅ |
| 一次性订阅消息模板 | ❌[23] | ❌[23] | ✅[23] |

## 5. AI 内容规则：标识、判定、限流

### 5.1 法规层（一手原文）

《人工智能生成合成内容标识办法》（国信办通字〔2025〕2 号，2025-03-07 印发，**2025-09-01 施行**）[27]：

- 标识分**显式标识**（文字/声音/图形，用户可明显感知）与**隐式标识**（写入文件元数据，含生成合成属性、服务提供者名称/编码、内容编号）[27]。
- 文本需在起始、末尾或中间适当位置加文字/符号提示，或在交互界面、文字周边加显著提示；图片/视频/音频各有对应要求[27]。
- 传播平台义务：核验元数据隐式标识 → 有则加提示；用户声明为 AI → 加「可能为 AI 生成」提示；无标识但检测到生成痕迹 → 标为「疑似 AI 生成」；并须提供声明功能[27]。
- **用户义务**：发布 AI 生成合成内容应主动声明并使用平台标识功能；**不得恶意删除、篡改、伪造、隐匿标识**[27]。
- 违反者由网信、电信、公安、广电等按职责处理[27]。

### 5.2 平台层（微信）

**2025-08-31「微信珊瑚安全」公告**（媒体转述官方公告原文要点）[28][29]：

- 平台按《标识办法》对 AI 生成合成内容添加**显式标识和隐式标识**，并对疑似 AI 内容做提示；
- **用户发布的内容为 AI 生成合成的，发布时需主动声明**；
- 不得删除/篡改/伪造/隐匿平台 AI 标识；不得用 AI 制作传播虚假、侵权信息；
- 违规将「视违规情况进行处罚」。

**2026-03-27 新增运营规范 3.27「非真人自动化创作行为」**（微信团队对媒体回应 + 媒体转述条文）[30][31]：

- 公众号和服务号**不得利用 AI、脚本、接口或其他自动化方式，替代真人完成内容创作、发布等流程**；
- 具体包括三类：① 脱离真实创作者表达，用 AI 生成/改写/拼接/搬运内容；② 通过脚本、程序托管等**自动化方式批量、连续发布**；③ 传播非真人自动化创作的教程、方法或服务；
- 处罚：内容侧「流量限制、删除」，账号侧「能力限制、封禁」[30][31]。
- **2026-04 已出现执行案例**：多位运营者后台文章被批量删除，提示「存在非真人自动化创作行为」[31]。

### 5.3 「AI 味」对推荐/广告资格的影响

- 官方**没有**「AI 味」这种判定标准，也没有公开的「AI 内容降权系数」→ ❓。
- 能确认的只有两条硬规则：① AI 内容**未声明**可被处罚[28][29]；② **非真人自动化创作/批量自动发布**会被限流、删文、能力限制、封禁[30][31]。
- 「AI 味重 → 推荐少 / 流量主被关」属于**社区经验**，官方文档无对应条款；可确认的间接事实是：广告资格与账号违规记录绑定（流量主申请要求无刷粉[8]，带货能力可被单独限制[19]）。→ 写作策略上应按「声明 + 人味 + 不批量」执行，而不是指望规避检测。

## 6. 注册流程：从零到发出第一篇

### 6.1 步骤清单（个人订阅号）

| # | 动作 | 关键点 / 官方依据 |
| --- | --- | --- |
| 1 | 准备：一个**未注册过公众平台**的邮箱、身份证、本人手机号、已实名的微信号（绑定银行卡） | 材料清单[1]；个人注册需邮箱[6] |
| 2 | 打开 mp.weixin.qq.com → 立即注册 → 选「公众号」（订阅号） | 服务号仅适合企业/组织[25] |

| 5 | 设置名称（4–30 字符，中英文数字）、功能介绍（4–120 字）、头像 | 名称规则[6]；简介规则[7] |
| 6 | 提交，等审核 / 通知中心 | 个人无主体验证环节；审核时长官方未给 ❓[1] |

| 9 | 变现开关：100 粉开流量主[8]；发过原创后邀请赞赏账户[9]；3 个月 + 3 篇原创开付费阅读[11] | — |

### 6.2 常见坑（都有官方依据）

- **名称**：4–30 字符（1 汉字 = 2 字符），只允许中文/英文/数字；**一年只能改 2 次**；命中保护词要提交佐证材料，审核 7 个工作日；改名后旧名有 2 天保护期[6]。
- **功能介绍**：4–120 字，**每自然月只能改 5 次**；含「微信、热线、兼职、相册、男科、服务」等字眼可能提交失败[7]。
- **留言**：新注册账号**没有留言功能**，且这是平台规则调整，不是设置问题[12]→ 别把「留言区广告」写进收入模型。
- **个人 ↔ 企业不可逆**：个人号不能认证[3]；订阅号不能迁移成服务号[14]；主体变更只能迁移且目标不能是个人[14]。
- **一人一号**：身份证已注册过个人号就到上限，换资料也没用[5]→ 上手前想清楚要不要把这个唯一名额给「试验号」。
- **企业订阅号也不是万能**：能认证、有发布 API、有菜单外链，但**不能微信支付**（只有服务号/政府媒体订阅号可以）[4]。

## 7. 两条路线的代价对比与推荐

### 7.1 对比表

| 维度 | A：个人主体 + 手动粘贴 | B：企业/个体户 + 认证 + API |
| --- | --- | --- |
| 现金成本 | 0 元 | 认证 **300 元/年**（一年一审，失败不退）[2] + 个体户/公司注册与记账报税（地方差异大，❓ 未核实）+ 对公账户（企业必选）[1] |
| 前置资质 | 身份证 + 实名微信 | 营业执照；企业需对公账户或法人验证；个体户可法人验证[1] |
| 账号名额 | 一身份证 1 个，用掉即止[5] | 同主体可开多个（流量主同主体上限 20）[8] |
| 群发频次 | 1 次/天[4] | 订阅号 1 次/天；服务号 4 次/月[4] |
| 发布 API | ❌ 2025-07 起回收[15] | ✅（依赖认证）[15] |
| 草稿箱/图片 API | [推断] 可用（待实测）[16][19][20] | ✅ |
| 微信支付 | ❌[3][4] | 服务号 ✅；企业订阅号 ❌[4] |
| 留言 | ❌ 新号无[12] | ❌ 新号同样无[12] |
| 每篇时间成本 | 手动粘贴/排版/校对，约 10–20 分钟（估算，非官方） | 首次开发 1–3 天（access_token 中控、IP 白名单、HTML/图片上传），此后几分钟 |
| 3.27 合规风险 | **最低**：人写、人发 | **较高**：用「接口/脚本」完成发布流程，正落在 3.27 禁止的「替代真人完成发布」表述内[30][31] |
| 额外运维 | 无 | IP 白名单（家庭宽带动态 IP 会报 40164）[23]；access_token 2 小时刷新[24]；等于需要一台固定出口的机器/云函数 |
| 试错/退出成本 | 低（可弃号，但名额不回） | 高（认证费不退；改主体要迁移 300 元 + 公证）[2][14] |

### 7.2 推荐

**默认选 A（个人订阅号 + 手动发布）**，理由不是「省钱」，而是三点结构性事实：

1. 你的目标（前端 × AI 高质量长文、个人使用、不部署服务器）与「发布 API」的价值不匹配：API 省下的是每篇十几分钟，却要付出 300 元/年 + 主体资质 + 固定 IP + 合规风险。
2. **3.27 新规下，「自动化发布」本身就是被点名的高风险行为**，而个人主体的「不能自动发布」恰好把风险挡在门外[30][31]。
3. 变现侧的门槛与主体/认证**无关**：100 粉流量主、原创赞赏、3 个月 + 3 篇付费阅读，个人号全都能开[8][9][11]。认证真正买的是微信支付、外链菜单、发布接口——这三样都要等你明确要做「付费社群/电商/多号矩阵」时才有意义。

**什么时候切 B**：
- 明确要接微信支付（课程/社群收款）→ 只能服务号 + 认证（且服务号群发只有 4 次/月）[4]；
- 要做多账号矩阵（同主体 20 个流量主）[8]；
- 已经验证内容能稳定涨粉、且确实需要「草稿自动生成 + 人审 + 手动点发布」的半自动流水线。

**折中路线（成本最低的自动化）**：留在 A，但用 `draft/add` + `uploadimg` 把 Markdown 排版结果推进草稿箱，人在后台预览、改标题、点发表。
- 好处：只自动化「排版」这个纯机械环节，创作与发布决策仍由人完成，离 3.27 的红线最远；
- 前提：个人主体草稿箱接口未被同步回收（[推断]，需实测）[16][19]；
- 仍需处理 IP 白名单（`40164`）[23]。

2. **流量主分成比例**：官方未公开；社区口径「原创 70% / 非原创 50%」[32][33] 无官方佐证。
3. **2026-03-31 计费改版（取消 CPM、纯 CPC）**：多篇社区文章口径一致[32][33]，但未找到官方公告/文档原文。
